Licence

Simple, offline licensing

No subscription server to phone home to, and no master password shared by every customer.

🔑

One key per computer that runs BuildCore

Each computer shows a request code; you send it and receive a licence key. Browsers that connect to it need no key, so the whole office is covered.

🗝️

Your company holds the master key

The administrator makes keys for the company's own computers from Administration › Licence keys, using the master password and the master key file (.bckey). Keep that file safe and backed up.

🛟

Forgot password works offline

Recovery code, a reset code from the administrator, the master key file, or a supplier reset key. No internet or phone call needed at 9 p.m. on a Friday.

⏳

Fair start

New installations ask for a key at first start. Computers updated with existing data get 15 days of grace, so work never stops during an update.

Windows may say Windows protected your PC because the installer is not code-signed. Click More info, then Run anyway. Ask us for a licence key or a price.
Updates

One file updates any version

Each update carries every earlier one and installs over any BuildCore from 1.6 onward.

  1. Backs up the program files.
  2. Copies the new version.
  3. Test-starts on an empty database and on a copy of your data.
  4. Puts everything back by itself if anything fails.
