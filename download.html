Install

New computer

  1. Close any open BuildCore window.
  2. Double-click BuildCore_Setup_2.35.0.exe, then Install. If asked, install the BuildCore program too, then Finish.
  3. Run the 2.48.0 update. When it says Done, press any key.
  4. Open BuildCore, click Copy beside the request code and send it to us. Paste the key you receive and click Activate.
Update

Computer that has BuildCore

  1. Close BuildCore on that computer.
  2. Unzip the download (right-click › Extract All) and double-click UPDATE_BuildCore_Complete_2.48.0.bat.
  3. The window backs up, copies and test-starts on a copy of your data. Wait for Done: BuildCore is updated to 2.48.0.
  4. Update every computer that runs BuildCore. Computers that only use a browser need nothing.
